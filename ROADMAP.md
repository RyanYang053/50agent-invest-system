# Roadmap

These are proposed milestones, not promised release dates or claims of completion. Open a focused issue to discuss scope, evidence and acceptance criteria.

## Already implemented in the launch candidate

- Product-first README and preserved engineering documentation.
- Fixture-based HTML preview and regression test.
- Contribution, security and issue guidance.

## Next milestones

- [ ] Interactive research trace for a reproducible fixture
- [ ] Pre-registered single-role vs multi-role comparison
- [ ] Verified provider integrations and independent role evaluation
- [ ] Public research report examples and clear model-cost accounting

## Non-goals

No live order submission, fabricated performance, bypassed controls or unsupported professional certification. Prioritize independent reproducibility and safe user experience over agent counts or marketing claims.
