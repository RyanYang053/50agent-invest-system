# Atlas Investment OS FAQ

## Are all 50 agents running at once?

No. The manifest describes logical roles, some deterministic and some model-backed. Execution depends on task routing, permissions, model certification and configuration.

## Can it trade live?

No. The separate paper pilot is disarmed by default and requires operator approval.

## Do I need an API key to try it?

Not for the fixture demo. Live research adapters and model calls have separate requirements and approvals.

## Does Atlas outperform the market?

That has not been established. Synthetic tests and retrospective studies are not evidence of prospective alpha.
