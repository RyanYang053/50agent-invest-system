# Financial conditions and liquidity diagnosis
1. Define liquidity: market execution liquidity, funding liquidity, or aggregate financial conditions. Do not substitute one for another.
2. Choose disclosed proxies before inspection: financing spreads, volatility, lending conditions and relevant balance-sheet observations. Record provider, unit, release time, transformation and missingness. Different publication frequencies are aligned using last available observations, not future interpolation.
3. Compare changes and standardized values against a fixed trailing sample, keeping all proxies and their signs visible. Do not infer a mechanical link from central bank balances to asset returns.
4. Test competing hypotheses such as risk-off repricing, supply changes and financing pressure. Identify which observations would distinguish them; report inconclusive if necessary.
5. Produce condition score, conflicting signals, evidence table and stress implications. No automatic allocation change.
Learning: monitor lagged predictive error against a predeclared benchmark and preserve negative findings. Official reference: FRED API https://fred.stlouisfed.org/docs/api/fred/ and ALFRED vintage data https://fred.stlouisfed.org/docs/api/fred/alfred.html .
