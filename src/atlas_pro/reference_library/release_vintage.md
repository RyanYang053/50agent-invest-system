# Inflation and growth release analysis
1. Identify series, frequency, unit, seasonal adjustment, base period and first public release timestamp. Freeze the as-of date. Do not use latest revised history as a first-release record.
2. For positive level data compute month-over-month and year-over-year growth from comparable observations. State whether the series is an index, level, percent or annualized growth. Annualize a periodic compounded growth rate only when the convention is appropriate.
3. Compare the new release to a timestamped pre-release expectation only if authorized and available; otherwise report the change, not a surprise.
4. Separate base effects, composition and revisions. Reconcile contribution arithmetic and identify alternative explanations; release data alone does not establish a causal market move.
5. Record current reading, prior vintage, revision, confidence limitations and next relevant scheduled release when verified.
Acceptance: independently recompute transformations and test a revision example; reject any observation first available after the cutoff.
References: BLS developer portal https://www.bls.gov/audience/developers.htm ; ALFRED https://fred.stlouisfed.org/docs/api/fred/alfred.html .
