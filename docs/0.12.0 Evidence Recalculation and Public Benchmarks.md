- G3: four distinct content-addressed JSON files for cases, corpus, retrieval/answers, and claim judgments. Recompute answerable Recall@10, material claim entailment, and scope/time/entity leaks. Require 500 distinct cases (at least 450 answerable), 450 material claims, at least 95% response coverage on answerable queries and 95% abstention on unanswerable queries if present. Reject missing joins, changed claim content, invalid citations, or signed metric mismatch. Gold labels and semantic entailment still require independent human adjudication. The data attestations themselves are not a proof of truth.
- G4/G9/G10: four distinct artifacts contain daily gross portfolio returns, benchmark total returns and daily risk-free return, all cost fractions, and all registered trials including failed/aborted ones. Verify raw source hashes, daily close timestamps and full NYSE sessions, common currency, pre-period freeze, evidence recording dates, cash-flow adjustments and complete costs. Calculate `net = (1 + gross) * (1 - cost_fraction) - 1`. Recompute compounded NAV, drawdown, arithmetic daily excess and a single-benchmark excess-return regression intercept. One-sided 95% familywise HAC confidence bounds with Bonferroni across all declared attempts and fixed lags 5/10/20; use the worst bound. Require >=252 daily observations, nondegenerate variance and design. Reject mismatched signed metrics; daily decimal units, not annualized figures. Reviewed evidence remains conditional on truthful sources, complete trial log, risk-matched benchmark, exposure factors, stationarity and externally timestamped records. Not an assurance of actual alpha, not a full multifactor attribution, no order permission.
- Fixed session enumeration when interval begins/ends on non-trading days (calendar padded by 7 days and filtered by actual open/close times). CI adds optional statsmodels comparison and real public-data developer experiment. Existing signatures and older evidence packages without the new artifacts will be blocked for G3/G4/G9/G10.

### G3 evidence format

Signed gate includes `rag_cases_hash`, `rag_results_hash`, `rag_claim_judgments_hash`, `rag_corpus_hash` in `artifact_hashes`. Every raw source must also appear in that list and exist by SHA256 filename. Schema examples are executable fixtures in `tests/test_evidence_recomputation.py`; they are deliberately synthetic, not review packages. `RAG_CASES_V1` locks `id`, query, security ID, decision timestamp, scope and gold document IDs. `RAG_CORPUS_V1` records document ID, security, scope, actual availability and raw hash. `RAG_RESULTS_V1` binds cases/corpus, top_k=10, run time, retrieved IDs, abstention and actual claims (ID, text, citations). `RAG_JUDGMENTS_V1` binds result hash, grades each claim with claim hash, material/entailed booleans and reviewer rationale, and provides grade time. Independent reviewers need to verify full corpus and rights, duplicate/paraphrase contamination, timestamps and actual source support.

### G4/G9/G10 evidence format

Signed gate includes `benchmark_hash`, `cost_model_hash`, `trial_registry_hash`, `returns_hash` and the hashes of raw source and individual trial result files. See executable fixtures. `PORTFOLIO_DAILY_V1`: mode, currency, pre-start frozen timestamp, selected trial ID, benchmark/cost hashes and daily rows (`at`, `recorded_at`, `evidence_hash`, `gross_return`, `cash_flow_adjusted`). `BENCHMARK_DAILY_V1`: benchmark ID/currency and daily rows with `return`, `risk_free_return`, `total_return`; `COST_DAILY_V1`: currency and daily rows with `cost_fraction`, `all_costs_included`. `PERFORMANCE_TRIALS_V1`: registered_at, selected_trial_id, returns_hash, and distinct trial IDs, status and distinct raw result hashes. Costs include actual modeled/real fees, spreads, financing, slippage and all relevant charges. The daily row must match the exchange close; the source record cannot precede the close. Forward/live rows require evidence recorded within three days; those timestamps are not authenticated by this code. G9/G10 additionally compare risk-adjusted CI and counted sessions. The gate still requires independent attestations for uncomputed metrics (e.g. regimes, risk breaches, reproducibility, peer comparisons).

## Actual real-data developer experiments

1. FinanceBench: official public noncommercial subset fetched through GitHub in development tool, 150 annotated questions, 32 companies, 84 documents and 168 annotated pages. Reference BM25 only, no answer/justification indexed. Global recall@1/5/10 = .203333/.382222/.494444, MRR .316655; company-known = .373333/.875556/1.0, MRR .606116; filing-known = .583333/.964444/1.0, MRR .797508. Restricted runs use oracle metadata, not validated entity resolution. The corpus contains annotated evidence pages only, not complete filings. The reference was executed in the connector JS tool, NOT the Atlas Python retrieval runtime. A local Python equivalent is provided for an operator's separately acquired official JSONL (Git blob SHA1 `4aef1d43a443474ba193f158f2baf70550ff528d`); tie-break differences may affect equal scores. Only fixture tests ran for the Python adapter locally because raw data transfer to the container failed. Do not redistribute the dataset or assume commercial/AI training rights. Source: https://www.patronus.ai/research/financebench and https://github.com/patronus-ai/financebench .
2. Actual statsmodels public-domain macrodata (FRED/BLS, 2009 vintage) 203 quarters, 1959Q1–2009Q3. Expanding-window, lagged-feature forecast of annualized log real GDP growth, 118 OOS observations 1980Q2–2009Q3. RMSE/MAE in annualized percentage points: mean 3.1730/2.1939; last available growth 3.6652/2.5531; Ridge 3.0277/2.2864; histogram boosting 3.2515/2.4633. Ridge slightly improves RMSE but not MAE, boosting underperforms mean. No selected winner or promotion. Revised vintage is not actual historical release availability, so this is NOT PIT. Source: https://github.com/statsmodels/statsmodels/tree/main/statsmodels/datasets/macrodata .
3. Actual public-domain Grunfeld industrial panel (1950 research, 11 selected firms, 220 rows, 1935–1954): 99 OOS annual log investment forecasts 1946–1954; lag-two baseline MAE .29681 and mean rank IC .93030; fixed Ridge MAE .26850 and mean rank IC .94040. Historical selected firms, no verified publication dates, not stock returns or a tradeable investment strategy. Source: https://github.com/statsmodels/statsmodels/tree/main/statsmodels/datasets/grunfeld .
4. Developer static scan parsed 61 source Python files; no direct eval/exec, pickle load, shell=True, os.system or narrow key-pattern matches in the scanned source/config/doc files at the checkpoint. Not comprehensive vulnerability scanning or independent red teaming. No Docker or new namespace access here; CI deployment checks are separate.
