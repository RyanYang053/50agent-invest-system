## Actual new capabilities and safe integration boundaries

| Component | Invocation | Required acceptance |
|---|---|---|
| Qlib | `oss_adapters.qlib_predictions`; `experiments.purged_panel_folds` | Run Qlib separately on authorized historical PIT universe; export explicit JSON scores, model/data hashes, signal and training-label cutoff and evidence IDs. Atlas re-resolves the records. No recorder pickle or model code loading. Missing names remain missing; no automatic trade. |
| RD-Agent / MLflow / DSPy | `experiments.experiment_request`, `review_experiment`, `promotion.compare_challenger` | External research worker only; sandbox, code review, trial history, data rights, fixed validation and holdout. Compare paired net log returns via moving-block bootstrap and Bonferroni-corrected tail. No autonomous deployment; not statistical proof of alpha. |
| LEAN | `oss_adapters.lean_equity_review` | Export independent net equity and separate total-return benchmark with starting value, exact locked ordered observation IDs and no external flows. Recalculate returns; confirm fees, slippage and corporate actions independently. Current external curve schema is an Atlas normalization contract, not a claim of automatic parsing every native LEAN version. |
| Inspect AI | `oss_adapters.inspect_responses` | Export stable case IDs, `EvalSample.output.completion`, completed/error fields; discard external grader scores and independently run Atlas locked structured grader. Raw logs may contain private data; never upload them. No automatic certification. |
| DuckDB | `oss_adapters.duckdb_pit` | Fixed local hash-pinned Parquet columns: security_id, field, period_end, available_at (explicit timezone), revision, value, evidence_id. Retention permission required, no arbitrary SQL or remote paths; query latest eligible revision per field/period. Verify every returned row against ledger before use. |
| Qdrant | `oss_adapters.LocalQdrantSnapshot`, `ResearchIndex.search(...,vector_backend=...)` | Local in-memory snapshot uses exact model version, vectors without text, source fingerprint, pre-filter by scope, security and PIT, and rehydrate in SQLite. No remote service. Any corpus change requires rebuild. Full manifest verification scans all vectors, so this is correctness-first, **not a proven scalable ANN speedup**. Benchmark before migrating persistent indexes. |
| Docling | `oss_adapters.docling_markdown` | Operator-provided local PDF + SHA256, local artifact directory, OS-enforced egress restriction, no remote services or plugins, OCR disabled. Returned Markdown is unverified, not a financial fact or page/cell citation. Review conversion, footnotes, units and licensing before `index_document`. |
| skfolio | `oss_adapters.skfolio_cvar` | Optional `Portfolio` CVaR comparison on identical aligned observations/weights; verify tail conventions; not execution authorization. Independent SciPy risk engine remains authoritative for supported shadow case. |
| QuantStats-inspired | `performance.paired_performance` | Exact expected session sequence, cost-net/cash-flow-adjusted total returns and benchmark; independently verify input. Annualized return withheld if fewer than annual_periods. No auto-download or external QuantStats call. |

See the updated catalog for all 18 projects. LangGraph/TradingAgents-style durable state and independent research review are in the existing `committee`/`workflow`; Promptfoo-style negative tests are local. OpenBB, ib_async and complete EdgarTools XBRL/segment processing remain external integration gaps. No assertion that every upstream capability is useful, implemented, or suitable for a financial production system.

## Usage

```bash
python -m pip install -e '.[market_calendar,test,quant]'
python -m pytest -q
# Optional data and risk integration tests (requires package repository access):
python -m pip install -e '.[warehouse,risk_crosscheck]'
python -m pytest -q tests/test_oss_adapters.py
# Existing screen command accepts --basis ttm; all existing policy/entitlement constraints remain.
atlas-screen --help
atlas-oss --help
```

`atlas-oss JOB.json --sha256 SHA256 [--evidence PRIVATE_LEDGER.sqlite]` accepts only a local hash-pinned normalized object `{ "kind": "qlib|lean|inspect|performance|challenger|duckdb", "payload": {...} }`. `payload` must match the corresponding typed Python function arguments; the `qlib` kind requires an existing authoritative ledger and passes its own resolver, not a caller-selected function. No order or shell kinds. Read `tests/test_oss_adapters.py` for executable synthetic examples. The `--sha256` is operator-supplied and proves exact bytes, **not** upstream identity. Do not place private artifacts or data in the public repository. Keep data/model/parser workers isolated at the OS/container level; a Python flag is not a sandbox. Install from audited pinned releases and verify dependencies and model weights licenses; optional extras are development ranges, not a production lockfile.

Use `ResearchModelRunner(...,embed=local_pinned_embedding,vector_backend=local_qdrant_snapshot)` to opt into local retrieval. `rag_eval.evaluate_retrieval` accepts the same backend, permitting direct FTS/vector recall and scope comparison. This doesn't grant model access to licensed/private data. Continue to require independent source-claim verification.

## TTM methodology

SEC point-in-time bridge for US-GAAP/USD operating companies: prior full FY + current fiscal YTD - prior comparable fiscal YTD. Latest available exact acceptance timestamp, compatible tag, units, fiscal year start, duration and prior period alignment required; missing, incompatible or future facts refuse a TTM snapshot. For FY end use full FY. YoY TTM revenue requires independently reconstructing comparable previous TTM. Instant balance-sheet items use exact latest period end. The optional `basis:ttm` in the research packet uses this same calculation, not a separate model estimate. Sources are deduplicated, old annual RAG content kept immutable. Existing annual calculations and all paper safety tests still pass. This does not fully normalize changes in fiscal calendar, leases, segment revenue, foreign issuers, share classes or every XBRL taxonomy; validate real issuer cases before using TTM rankings. Historical SEC acceptance is a replay proxy, not proof of exact historical vendor availability.
