# Agent memory foundation

50 role-specific namespaces and domain labels, separate local SQLite files, trusted operator role binding. Candidate notes are quarantined; two independent signed reviews must attest domain relevance, evidence entailment, privacy and data rights, exact content and current Skill. Public-only reviewed annotations can enter the model context, not the evidence citation allowlist. Private/local memory stays local. Shared source facts remain in the existing scoped RAG; cross-role sharing requires an explicit public-source proposal and a new recipient review. Topic conflict requires explicit supersession; revoke is fail-closed, re-propose/review to restore. Historical queries cannot see future-created/approved notes; current revoked/expired material is excluded. Episodes record task/result hashes and status, never raw model outputs or account inputs. No automatic knowledge extraction, online model fine-tuning, autonomous relevance verification, full semantic search, independent security certification or trading authority. Domain labels are explicit allowlists, not semantic classification. Local deterministic roles may query their own reviewed notes via operator console; notes do not change numerical algorithms. Operator CLI and Python service are trusted, not exposed as arbitrary model tools. OS/process isolation and external audit are required against malicious code or local administrators. Independent review signatures are attestations, not proof. Existing role certification invalidates when runtime source changes.

Usage: atlas-memory --data-dir PRIVATE --trust TRUST.json catalog; propose/approve/search/revoke/share subcommands. Use --memory-trust TRUST.json on atlas-core run-role or screen-research for reviewed annotations. Keys remain outside repo. No keys, data or notes committed.
