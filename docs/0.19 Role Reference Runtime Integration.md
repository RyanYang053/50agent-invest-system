# 0.19 candidate: role reference runtime integration (partial milestone)

The task dispatcher loads each of the 50 role packs, verifies every assigned bundled
document's exact Git blob hash, performs a local role-scoped lexical query and
returns a receipt containing source IDs, hashes and excerpt offsets (no text).
All 29 specialized public memo routes now include original, bounded,
reference-informed method checks tied to the verified source versions. Raw
upstream text stays local and is never added to provider payloads. All 21 local
diagnostics verify their own reference context before dispatch; their existing
numerical implementations remain unchanged. This is not evidence that a local
algorithm executed an external engine or that a model understood a document.

The 33-source catalog consists of 15 upstream files, seven original guides,
ten unbundled external resources, and one existing internal runtime reference.
Unbundled sources get an explicit route status, not fabricated ingestion or
connectivity. SEC, ALFRED and Bank of Canada have existing operator-configured
adapters; French research archives and FinanceBench have separate evaluation
workflows. Damodaran, CRA, BLS, OCC and NIST require further source-specific
integration and rights checks. FinanceBench stays out of learning context.

New tests cover 50 reference contexts, 29 mock provider prompt paths, 21 mock
local dispatch paths, the entire source catalog, and fail-closed reference errors.
These are developer tests, not independent competence tests. Existing numerical
tests remain necessary. Changes invalidate runtime-bound competence reviews;
real paid calls still require valid signed reviews and explicit permission.
No broker permission, risk policy or strategy promotion changes.

Still outstanding: real source ingestion and update scheduling, authenticated
data-provider verification, actual external engine installation and comparisons,
independent professional competency evaluations, and audited autonomous
learning / challenger promotion. Do not describe this candidate as completion of
all ten acceptance gates or 50 independently qualified employees.
